USB Restoration Tool
====================

USB Restoration Tool restores USB drives that were modified by ISO writers,
Linux installers, or boot media tools.

How to run
----------

1. Extract this ZIP.
2. Double-click USBRestorationTool.exe.
3. Approve the Windows Administrator prompt.
4. Select the USB drive you want to restore.
5. Type the confirmation phrase shown by the app.

Important
---------

Restoring a drive erases every partition and file on the selected USB drive.
Only continue when you are certain the selected disk is disposable or backed up.

This build restores drives to one GPT + exFAT volume labeled USB.

Publisher signature
-------------------

Some release channels distribute unsigned builds. Windows SmartScreen may show
a warning for unsigned executables. Verify the release hash before running.
